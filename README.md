# Run and deploy on Vercel

This project is a `Vite + React + TypeScript` frontend and is ready to deploy on `Vercel`.

## Run locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Deploy to Vercel

1. Import the repository into `Vercel`.
2. Keep the default framework preset as `Vite`.
3. Deploy.

Build settings used by Vercel:

- Build command: `npm run build`
- Output directory: `dist`
